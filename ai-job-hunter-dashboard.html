02 / Подготовка резюме и письма

Персонализация на основе доказуемого опыта, а не генерация «красивых» фактов.

91факт в профиле кандидата с дословными цитатами
2–4вызова модели на подготовку пакета в зафиксированном процессе
A
Requirement Extractor

Выделяет из вакансии требования, приоритеты и язык работодателя.

B
Evidence Mapper

Связывает требования с фактами кандидата. Цитаты и ссылки проверяются кодом.

C
Resume Tailor + Cover Letter Writer

Собирают согласованную пару документов под конкретную роль.

D
Quality Auditor

Проверяет непротиворечивость, подтверждение утверждений и требования к итоговому формату.

Идемпотентность: для идентичного входа уже готовый пакет может возвращаться из кэша без повторного вызова модели. Документы остаются версиями с контрольными хешами и отчётом QA.

03 / Контроль качества и активность вакансии

Сначала проверка допуска, затем приоритизация и подготовка отклика.

✓
Шлюз активности HeadHunter

Карточка проверяется под авторизованным аккаунтом. «В архиве» — исключить; неизвестный статус не допускает вакансию в шорт-лист.

✓
ОТК-0…6

Набор проверок охватывает целостность, допуск вакансии, план резюме, пакет документов и проверки до/после действий на HH. В проектном журнале зафиксировано 145 зелёных тестов на 23 октября.

✓
Актуальные статусы, а не предположения

Статус считается подтверждённым только при наличии свежего свидетельства; источник ручной проверки подписан как hh_manual.

✓
Ручной топ — осознанное решение

Основной топ остаётся курируемым человеком по матрице критериев. Новый кандидат не попадает в приоритет автоматически лишь потому, что прошёл фильтр.

04 / Техническая архитектура

Оркестрация, детерминированная логика и языковые задачи разведены по компонентам.

01
n8n

Запускает расписание и связывает этапы процесса; повторные сборы ограничиваются защитой от слишком частого запуска.

02
Python · FastAPI · SQLite

Bridge отвечает за состояние, API, фильтры, идемпотентность, валидацию и сохранение данных.

03
Claude и вспомогательные агенты

Используются на ограниченных языковых задачах: разбор требований, сопоставление доказательств, документы и аудит.

04
Human-in-the-loop

Человек выбирает вакансию, проверяет комплект и подтверждает отправку. Автоматическая отправка откликов отключена.

Граница безопасности: рабочая база, резюме, cookies, токены и локальные сервисы не публикуются в этой витрине. Прямой applicant-side API HH для записи в проектных заметках был заблокирован ответом 403; отправка выполнялась вручную после проверки.
