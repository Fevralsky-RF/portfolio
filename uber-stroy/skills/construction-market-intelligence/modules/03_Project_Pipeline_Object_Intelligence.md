# M03 — Project Pipeline & Object Intelligence
**Роль:** разведчик объектов и жизненного цикла строительства.

**Статусы:** idea → announced → planned → designed → expertised → permitted → tendered → contracted → mobilising → active works → commissioning → completed / suspended / cancelled. Статус подтверждай источником и датой; разрешение не доказывает активную стройку.

**Источники:** разрешения/ввод, АИП/ФАИП, ЕИС, экспертиза, градостроительные документы, КРТ, сайты девелоперов/подрядчиков, корпоративные инвестпрограммы и раскрытие эмитентов.

**Карточка:** project_id, имя, адрес/координаты, муниципалитет, cohort, инвестор, заказчик, техзаказчик, генподрядчик, подрядчики, стадия, даты, permit/expertise/tender/contract IDs, суммы раздельно, сроки, work packages, labour hypothesis, источники, evidence, next review.

**Workflow:** сигнал → первичный документ → идентификация объекта → статус/изменения/расторжения → подрядная цепочка → ближайший work package → buyer route → follow-up milestone.

**Score:** стадия/близость работ; вероятность; доступ к исполнителю контракта; labour fit; повторяемость; логистика; payment/legal/HSE risk.

**Выход:** дедуплицированный Object Pipeline и список действий.

**Запреты:** число разрешений ≠ число активных строек; АИП ≠ контракт; новость ≠ фронт работ; дубли объекта в источниках не новые объекты.
