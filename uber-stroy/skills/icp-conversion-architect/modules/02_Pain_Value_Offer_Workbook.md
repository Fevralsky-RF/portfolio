# Module 02 — Pain, Value & Offer

## Workflow
1. Categorise pain: operational, financial, risk, cognitive, emotional, social/political, growth constraint.
2. Describe situation, trigger, frequency, consequences and existing workaround.
3. Define desired progress and proof required.
4. Map only product capabilities that truly address the pain.
5. Draft one core promise plus alternatives.
6. Attach mechanism, evidence, conditions, limitations and CTA.
7. Red-team the offer for unsupported guarantees and delivery gaps.

## Output
Pain-to-Value Matrix + Value Proposition + Message House + offer variants + claim/proof register.
