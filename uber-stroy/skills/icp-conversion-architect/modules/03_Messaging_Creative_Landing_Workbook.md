# Module 03 — Messaging, Creative & Landing

## Message sequence
Core promise → problem recognition → stakes → solution mechanism → differentiation → proof → objections → CTA.

## Creative principles
Each concept must target one ICP and one buying situation. Show the real context, role and mechanism. The image is not a substitute for proof; staged visuals must not look like verified customer outcomes.

## Landing sequence
Hero → situation/pain → desired state → mechanism → use cases → proof → process → objections → offer → form/CTA → trust/privacy.

## Mobile rules
Prioritise headline, primary action and key visual. Check crop, readable type, touch targets, form keyboards, sticky CTA and no horizontal overflow.

## Output
Message House + Creative Pack + page wire/content architecture + visual storyboard + form spec.
