# Module 04 — CRO & Experimentation

## Audit areas
Audience clarity, message match, offer clarity, pain relevance, mechanism, proof, objections, CTA, friction, mobile UX, technical integrity, trust/privacy.

## Prioritisation
For every issue: evidence → user impact → severity → hypothesis → proposed change → metric → guardrail → effort.

## Experiment method
Set baseline, one variable, control/variant, primary metric, guardrails, segment and success/inconclusive criteria. Never claim significance from insufficient samples. Use qualitative usability tests when traffic is low.

## Output
Scored CRO audit + ordered backlog + experiment cards + documented learnings.
