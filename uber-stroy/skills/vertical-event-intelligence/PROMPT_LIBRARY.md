# Prompt Library

1. **EVENT_RADAR** — «Найди события по вертикалям [..], регион [..], период [..]. Проверь первоисточники, оцени по 100-балльной модели, отдели заявленную аудиторию от подтверждённых участников».
2. **EVENT_SCORE** — «Сравни события [..] для вертикалей [..]. Рассчитай score, укажи источники, неизвестные поля, риск поездки и рекомендацию».
3. **VERTICAL_DEEP_DIVE** — «Разбери вертикаль [..]: заказчики, цепочка контрактов, buying committee, типовые объекты, work packages, допуски, сезонность, события и ассоциации».
4. **ACCOUNT_MAP** — «По программе события составь target-account map. Укажи только подтверждённые компании и публично подтверждённые роли; не угадывай посетителей».
5. **PRE_EVENT_SPRINT** — «Собери tier A/B/C, поводы касания, индивидуальные сообщения и план назначений. Не отправляй сообщения без моего одобрения».
6. **FIELD_COPILOT** — «Подготовь discovery script на мероприятие для [вертикаль/роль], 8 вопросов, признаки квалифицированной потребности и красные флаги».
7. **OPPORTUNITY_QUALIFY** — «Преобразуй заметки встречи в карточку opportunity: объект, работа, объём, срок, роли, плательщик, HSE, допуски, документы, следующий шаг, неизвестные поля».
8. **FOLLOW_UP** — «Составь персональный follow-up по заметкам [..], ссылаясь только на согласованные темы и предлагая конкретный следующий шаг».
9. **EVENT_ROI** — «Посчитай стоимость события, sourced/influenced pipeline, встречи, квалифицированные потребности, пилоты, оплаченные смены и contribution margin».
